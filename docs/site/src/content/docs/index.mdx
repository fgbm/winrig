winrig is an MCP server for the remote administration of Windows hosts over WinRM/NTLM. It is the Rust successor of the Python project `win-mcp-server`, and it ships as one static binary without a container or an interpreter.

Enter the AD password one time through `winrig setup`. The server keeps the password only as authenticated ciphertext, under a key that stays at the client. It never writes the password in clear text into the client configuration.

## Key properties

- **Two modes.** The server runs as an HTTP service (`winrig serve`) or as a local stdio process (`winrig stdio`).
- **One process for each profile.** `winrig setup` creates an encrypted profile and prints the profile token one time. A second process on the same profile refuses to start and points to the HTTP mode.
- **Two secrets.** A request authenticates with the shared secret (the header path with `X-AD-User`) or with a profile token.
- **Confirmation for each modification.** A modifying tool requires the explicit confirmation of the operator. Without a confirmation channel, the tool refuses to run.
- **Protected operations.** Deletion and `write_file` reject protected paths and reparse points.
- **No secrets on disk.** The profile file holds only authenticated ciphertext. The profile token stays at the client.
- **37 tools**, plus `write_file` when the operator enables it. The tools cover the file system, services, the registry, event logs, certificates, processes, the network and scheduled tasks.
