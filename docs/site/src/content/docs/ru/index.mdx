winrig — MCP-сервер для удалённого администрирования Windows-хостов по WinRM/NTLM. Это преемник Python-проекта `win-mcp-server` на Rust. Проект поставляет один статический бинарь без контейнера и интерпретатора.

Введите пароль AD один раз через `winrig setup`. Сервер хранит пароль только как аутентифицированный шифртекст. Ключ остаётся у клиента. Сервер никогда не пишет пароль в конфигурацию клиента открытым текстом.

## Ключевые свойства

- **Два режима.** Сервер работает как HTTP-сервис (`winrig serve`) или как локальный stdio-процесс (`winrig stdio`).
- **Один процесс на профиль.** `winrig setup` создаёт шифрованный профиль и печатает токен профиля один раз. Второй процесс на том же профиле отказывает в старте и указывает на HTTP-режим.
- **Два секрета.** Запрос аутентифицируется общим секретом (путь по заголовкам с `X-AD-User`) или токеном профиля.
- **Подтверждение для каждой модификации.** Модифицирующий инструмент требует явного подтверждения оператора. Без канала подтверждения инструмент отказывает.
- **Защищённые операции.** Удаление и `write_file` отвергают защищённые пути и точки повторной обработки.
- **Никаких секретов на диске.** В файле профиля лежит только аутентифицированный шифртекст. Токен профиля остаётся у клиента.
- **41 инструментов** плюс `write_file`, когда оператор его включит. Инструменты покрывают файловую систему, службы, реестр, журналы событий, сертификаты, процессы, сеть и запланированные задачи.
