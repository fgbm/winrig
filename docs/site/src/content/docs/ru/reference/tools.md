title: Инструменты
description: Инструменты только для чтения и модифицирующие инструменты winrig с переключателями, которые включают запись.
---

Бинарь объявляет 43 инструментов плюс `write_file`, когда оператор его включит. Инструменты только для чтения не требуют подтверждения. Модифицирующие инструменты требуют явного подтверждения оператора (DR-5).

## Сессия

| Инструмент | Описание |
|------|-------------|
| `connect` | Открыть WinRM-сессию к Windows-хосту и вернуть `session_id` (HTTP 5985 или HTTPS 5986 через `use_ssl`) |
| `disconnect` | Закрыть активную WinRM-сессию |
| `list_sessions` | Список активных WinRM-сессий с деталями использования |

## Инструменты только для чтения

### Файловая система

| Инструмент | Описание |
|------|-------------|
| `list_directory` | Список файлов и каталогов по пути |
| `find_files` | Рекурсивный поиск файлов по шаблону |
| `read_file` | Чтение содержимого файла с нумерацией строк. В режиме хвоста можно отбросить строки, которые содержат заданный текст |
| `search_file_content` | Текстовый поиск в файле или по каталогу, аналог grep. Инструмент может вернуть последние совпадения, посчитать совпадения и отфильтровать строки по отметке времени в начале строки |
| `file_info` | Метаданные файла или каталога в JSON |
| `compare_files` | Построчный diff двух файлов |

### Диагностика системы

| Инструмент | Описание |
|------|-------------|
| `get_event_log` | Журнал событий Windows: падения, отказы служб, ошибки аутентификации |
| `list_event_logs` | Каналы журнала событий с числом записей и признаком включения |
| `get_services` | Сводка служб или полные детали по каждой службе в JSON |
| `get_service_config` | Одна служба: тип запуска (Automatic, AutomaticDelayed, Manual или Disabled), учётная запись, путь к бинарю и действия восстановления с действием, задержкой и периодом сброса |
| `list_processes` | Процессы с сортировкой по CPU, памяти или дескрипторам |
| `get_open_handles` | Процессы, которые держат файл открытым: PID, имя и время запуска. Инструмент использует Restart Manager, поэтому Sysinternals `handle.exe` на хосте не нужен |
| `get_printers` | Принтеры: имя общего ресурса, драйвер, порт, хост и номер порта, состояние в виде расшифрованных флагов и число заданий |
| `get_print_jobs` | Задания печати одного принтера. Имя документа и владелец скрыты, пока не задан `include_personal_data` |
| `get_system_info` | Версия ОС, uptime, RAM, число CPU, домен, часовой пояс |
| `get_disk_space` | Место на всех фиксированных дисках |
| `get_perf_snapshot` | Снимок CPU, памяти, дискового I/O и сети, не зависящий от локали |
| `get_registry` | Чтение ключа или значения реестра и, по запросу, имён дочерних ключей (только чтение) |
| `get_certificates` | Сертификаты личного хранилища с сортировкой по дням до истечения |
| `get_network_config` | IP, шлюз и DNS по каждому сетевому адаптеру |
| `test_network` | ICMP-пинг или проверка TCP-порта с удалённого хоста |

### Идентичность и конфигурация

| Инструмент | Описание |
|------|-------------|
| `get_environment_variables` | Переменные окружения по областям |
| `get_scheduled_tasks` | Запланированные задачи с последним/следующим запуском и результатом |
| `get_local_users` | Локальные учётные записи со статусом и последним входом |
| `get_user_groups` | Членство в локальных группах |
| `get_security_context` | Идентичность текущей сессии, группы, привилегии |
| `get_permissions` | Записи ACL для файлов и каталогов |

### Сеть и ПО

| Инструмент | Описание |
|------|-------------|
| `get_tcp_connections` | Активные TCP-соединения с фильтром по состоянию, порту, PID или имени процесса и необязательной сводкой по группам |
| `get_dns_cache` | Локальный кэш DNS-клиента |
| `get_installed_software` | Установленное ПО из 64- и 32-битных ключей удаления |
| `resolve_dns_name` | Цепочка разрешения DNS с удалённого сервера |

## Active Directory — решено, но не построено

Ни одного из этих инструментов в бинаре сегодня нет. Раздел фиксирует решение ([ADR-0014](https://github.com/fgbm/winrig/blob/main/docs/adr/0014-active-directory.md), срезы W19–W21), а не возможность. Агент видит WinRM и хост в домене и предполагает, что каталог доступен. Но каталог не доступен.

Инструменты только для чтения, опрос через `System.DirectoryServices`, а не командлетами RSAT:

| Инструмент | Описание |
|------|-------------|
| `get_ad_object` | Один пользователь, группа или компьютер: состояние учётной записи, сроки пароля, последний вход, DN, OU |
| `get_ad_membership` | Членство в обе стороны, при необходимости вложенное |
| `find_ad_objects` | Поиск по имени или `sAMAccountName` с потолком результатов |
| `get_ad_domain_info` | Домен, лес, уровни функционирования, роли FSMO, контроллеры, доверия, сайты, парольная политика и PSO |
| `get_ad_health` | Партнёры репликации и отставание, службы NTDS/DNS/ADWS/W32Time, состояние SYSVOL |
| `get_ad_stale_objects` | Залежавшиеся пользователи и компьютеры по `lastLogonTimestamp` и `pwdLastSet` |

Запись в каталог (срезы W20–W21) намеренно оставлена за пределами первой волны. По умолчанию она будет выключена за `WINRIG_ALLOW_AD_WRITE`. Текущий бинарь эту переменную не читает.

## Модифицирующие инструменты

Эти инструменты меняют хост и требуют подтверждения.

| Инструмент | Описание |
|------|-------------|
| `restart_service` / `stop_service` / `start_service` | Управление службами с состоянием до и после. `stop_service` проверяет останов: ждёт `wait_seconds` (по умолчанию 15), читает состояние и события 7031/7034/7036 журнала System и сообщает ошибкой, если служба снова запустилась. При `disable=true` он задаёт тип запуска Disabled до останова |
| `set_service_start_type` | Задать тип запуска (Automatic, AutomaticDelayed, Manual или Disabled). Подтверждение показывает текущий и новый тип запуска. Инструмент отвергает службу, критичную для удалённого сеанса |
| `kill_process` | Принудительное завершение процесса по PID |
| `set_registry` | Запись значения реестра с показом старого и нового |
| `delete_file` / `delete_directory` | Удаление с запросом подтверждения; инструмент отвергает защищённые пути, в том числе по фактическому расположению системы на хосте |
| `flush_dns` | Очистка кэша DNS-клиента |
| `write_file` | Запись файла с заменой целиком. **Выключен по умолчанию**: задайте `WINRIG_ALLOW_FILE_WRITE=true`, иначе сервер не объявляет инструмент и вызвать его нельзя |

## Переключатели, которые включают модифицирующие инструменты

| Переключатель | Действие |
|--------|--------|
| `WINRIG_ALLOW_FILE_WRITE=true` | Объявляет инструмент `write_file`. Пока значение `false`, сервер удаляет инструмент из роутера |
| `WINRIG_MAX_WRITE_BYTES` | Наибольшее содержимое, которое принимает `write_file`, в байтах (по умолчанию 64 КиБ) |
| `WINRIG_ALLOW_INSECURE_TLS=true` | Разрешает `verify_cert=false` в `connect`. По умолчанию сервер его отвергает |

:::danger
`delete_file`, `delete_directory` и `write_file` отвергают защищённые пути и точки повторной обработки. Не вызывайте их для корня тома или системного каталога. Возможна потеря данных.
:::

:::note
Модифицирующие инструменты в Active Directory не построены. Переменная `WINRIG_ALLOW_AD_WRITE` в текущем бинаре ничего не делает.
:::
